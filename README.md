# ロト数字選択スタジオ

ロト6・ロト7の過去24回の本数字を分析し、指定ルールで候補を生成するブラウザアプリ。

- 過去24回で3〜4回出現した数字をちょうど3個
- 前回の本数字を合計1〜2個
- 前回数字と隣接数字で連続ペア1組

公平な抽せんでは各組み合わせの当選確率は同じです。このルールによって当選確率が上がる根拠はありません。

## 公開

GitHubのSettings → Pages → Deploy from a branchでmainと/(root)を選択します。index.htmlを静的配信するため、ビルド不要です。

## データ

2026年10月14日にhttps://kujishirube.info/ から取得した本数字24回分を収録。ロト6は第2122〜2145回、ロト7は第675〜698回。ボーナス数字は除外しています。

表示データは収集時点のスナップショットです。GitHub Pagesから外部サイトの抽せん結果を直接自動収集する機能は含みません。更新時は最新24回分を収集してindex.htmlのhistory-dataを更新します。CSVには本数字のみを新しい順に格納しています。

手入力・CSV読込データは訪問者自身のブラウザに保存されます。
